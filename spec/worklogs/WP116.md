# WP116 — Aptitude

Aptitude lets one chosen skill be bought to 7 at creation, and raises its rating ceiling to 13
(p. 72). Before this WP the quality was unoffered, and `engine/skills.py` said so in a comment.

## What landed

- **The quality**: the classifier reads `<selectskill><max>1</max>` as a `skill_maximum` flat bonus
  whose target is the pick's choice. `choice_kind` is `"skill"`, the same list WP115's Loss of
  Confidence uses. Aptitude is once-only (no `<limit>`).
- **`ImprovementType.SKILL_MAXIMUM`** (target: skill name). `engine/skills.py` gained
  `skill_maximum_bonuses(character)` and `purchase_maximum(skill, bonuses)`.
  - `create_skill_allocation` takes `maximum_bonus` (skill name → levels). A skill's cap is 6 + its
    bonus. A group's cap stays 6.
  - `create_karma_skill_selection` reads the bonus off the character it already takes.
  - `natural_skill_rating` clamps at 6 + bonus. `skill_rating` clamps at 12 + bonus.
- **Callers**: the save loader passes the bonus. Qualities are already applied at that point, so a
  saved Pistols 7 reloads. The skills route passes it on submit and on the stale re-check. Each skill
  row carries its own `max_rating`, so the input's `max` is 7 for the Aptitude skill.
- **Offered count**: 81 → 82. Only WP117's four qualities are left to offer.
- The "Aptitude deliberately not modeled" comment in `engine/skills.py` is gone.

## Decisions

- **The purchase cap is passed in, not read off an Improvement index.** `create_skill_allocation`
  has never taken a `Character`, and the priority half of the spend is validated before one exists
  in some callers. A plain name → levels map keeps it that way. It mirrors WP112's `maximum_bonus`
  for attributes.
- **No new stale path.** Removing Aptitude with the skill still at 7 is caught by the skills page's
  existing WP19 re-validation, which now reads the character's *current* bonuses.

## Verification

- `uv run python -m pytest -q`: 1561 passed. `tests/unit/test_aptitude_wp116.py` covers the plan's
  acceptance (Pistols 7 is allowed and Blades 7 rejected), the no-Aptitude case, the Karma path
  (6 → 7 for 14 Karma), the 13-vs-12 ceiling, and a web round trip: 7 is rejected, then accepted
  after picking Aptitude, then saved and reloaded.
- `ruff check`, `ruff format --check`, `mypy src`: clean.
