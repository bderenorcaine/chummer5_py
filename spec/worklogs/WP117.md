# WP117 — Qualities that change purchase rules: Uncouth, Uneducated, Incompetent, Sensitive System

These are the last four unoffered core qualities. With them, every purchasable in-scope row is
offered: 86 through `mvp_quality_catalog`, plus Mentor Spirit per character, which makes the 87 the
WP108 test named.

## What landed

- **Classifier**: the four `*costmultiplier` tags (a 200% cost is stored as +100 extra percent),
  `skillgroupcategorydisable`, `blockskillcategorydefaulting`, `skillgroupdisablechoice` (choice
  kind `skill_group`), `cyberwaretotalessmultiplier` and `disablebioware`. Nine new
  `ImprovementType`s mirror them. Uncouth gets a rulebook-wins defaulting block for Social Active.
- **`SkillPurchaseRules`** in `engine/skills.py`, built by `skill_purchase_rules(character)`. It
  replaces WP116's `maximum_bonus` parameter.
  - `create_skill_allocation` prices points through `skill_points_spent`, which doubles a Social
    skill's rating *and* specialization points for Uncouth. It also rejects an Uncouth Social group
    and Incompetent's group and member skills.
  - `create_karma_skill_selection` raises skill, group and specialization Karma by the category
    percent, and rejects the same banned groups and skills.
  - The skills page's remaining-points number uses `skill_points_spent` too.
- **Unaware**: `is_unaware(character, skill)`, when a category's defaulting is blocked or the skill
  is in Incompetent's group. `dice_pool` then returns 0 at rating 0 instead of defaulting.
- **Knowledge**: `create_karma_knowledge_selection` doubles Academic/Professional Karma for
  Uneducated.
- **Sensitive System**: `create_cyberware_tree_selection(essence_multiplier=)` scales every node's
  Essence cost. `cyberware_essence_multiplier(character)` supplies it in the save loader, the
  cyberware route and the picker's per-unit Essence column. `create_bioware_selection(
  bioware_disabled=)` rejects any purchase. The qualities route re-costs a committed tree when the
  quality is picked or dropped (`_reprice_cyberware_essence`).
- **Incompetent's choice**: every active skill group except Tasking. The magic groups are offered
  only to a Magician (or, once WP121 lands, an Aspected Magician).
- **Registry**: four notes and four Project Overview rows.

## Decisions

See the decisions log's WP117 entry: Uneducated doubles only Karma, Uncouth's unaware rule is a
rulebook addition, Incompetent bans member skills, and how Sensitive System re-costs a committed
tree. One smaller call: two cost sources combine by adding their percents, not by multiplying.
Nothing in the core data stacks two of them, so the choice is invisible today.

## Traps

- **`B008`**: a dataclass instance as a default argument trips ruff. The shared default is the
  module-level `NO_PURCHASE_RULES`.
- **Test-side**: a Human's CHA is 1 + points, and Skills A's 46 points can't all go on one skill at
  cap 6. The first draft of the tests got both wrong.
- **Importing the cyberware route from the qualities route** is safe: the cyberware route doesn't
  import the qualities route, so there's no cycle.
