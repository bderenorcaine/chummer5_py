# WP118 — Adept skill restrictions, and the Astral Perception power

This WP fixes the phase file's Finding 4. Since WP61, an Adept had been offered every Magical Active
skill, against p. 69.

## What landed

- **Astral Perception** is offered. The power classifier reads `<unlockskills name="Assensing">` as
  an `unlock_skill` bonus, which becomes `ImprovementType.SKILL_UNLOCKED` ("Assensing"). `Power`
  gained an `unmodeled_effect_note` (the astral-perception half), which the sheet's existing collector
  already walks. There is one Project Overview row. WP119/WP120 add the other powers' notes the same
  way.
- **The bans are in the engine.** `skill_purchase_rules(character)` adds, for an Adept, Sorcery,
  Conjuring and Enchanting to `banned_groups` (each bans its member skills too), and Assensing to
  `banned_skills` unless unlocked. WP117's Incompetent group moved into the same map.
  `create_skill_allocation` and `create_karma_skill_selection` reject any of them via
  `SkillPurchaseRules.skill_blocked` / `group_blocked`.
- **The pickers** (`web/catalogs.offered_skills` / `offered_skill_groups`) filter through the same
  rules. The WP61 comment there is corrected.
- **The save loader** now builds the skill allocation after the Talent and powers. Its rules see the
  Talent through `replace(character, magic_type=...)` and the unlock through the applied power.

## Decisions

See the decisions log (2026-09-26, WP118). In short: one ban mechanism with reasons; the pickers
hide banned rows (reversing WP117's call); the Talent grant's Assensing is left to WP135.

## Checks the plan asked for

- **Wesson** buys no magical skills (his individual skills are Social, Technical, Physical, Vehicle
  and Pistols; his groups are Influence and Athletics), so the rule doesn't touch his import. The
  existing fixture tests pass unchanged.
- **A Magician → Adept switch** keeps the committed skill spend, and the skills page shows the
  WP19 warning with the Adept reason. Tested.
