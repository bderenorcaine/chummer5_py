# WP129 — Implants that replace racial traits

Step Six's "Cyberware/bioware may remove a racial bonus" (p. 94) now shows on the sheet:

- Cybereyes strike through an Elf's, Ork's, Dwarf's or Troll's racial Low-Light or Thermographic
  Vision, unless the eyes carry the matching plugin.
- Orthoskin or Dermal Plating strikes through a Troll's racial dermal armor.

## Research

See the learnings entry for the p. 94 text, and for the replacement pairs that were looked for and
not found. The Orthoskin question the plan raised ("replaces or stacks?") was already settled in
code: WP109/WP113 put the racial armor in legacy's `group="0"` dedup group with Dermal Plating and
Orthoskin, so the higher value wins. That matches "replaces", since an implant is always rating 1
or more.

## What landed

- **Engine** (`engine/derived.py`): `suppressed_racial_traits(character)` returns
  `SuppressedRacialTrait(trait, replaced_by)` records. It uses `CYBEREYES`,
  `RACIAL_VISION_PLUGINS`, `SKIN_ARMOR_AUGMENTATIONS` and `DERMAL_ARMOR_TRAIT`. It changes no
  number: the vision qualities carry no computed effect, and the Armor is already correct.
- **Web**:
  - The sheet's "Free from metatype" list renders a replaced quality as
    `<s>Low-Light Vision</s> (replaced by Cybereyes Basic System)`.
  - A new "Racial dermal armor" row for Trolls is struck through when replaced.
  - Three new strings.

## Decisions

- **Display only.** Nothing mechanical hangs on a racial vision quality in this engine. The one
  number involved, Armor, was already right.
- **Dermal Plating replaces the dermal armor too, following legacy's grouping.** The book names
  only orthoskin (see the learnings).
- **Any pair of cybereyes with the plugin keeps the trait.** A character with two cybereye
  purchases is unusual, and the book speaks of "the cybereyes" as one system.

## Verification

- `uv run python -m pytest -q`: all pass (1690). `tests/unit/test_racial_trait_replacement_wp129.py`
  covers:
  - Elf cybereyes, with and without the Low-Light plugin;
  - a Dwarf needing the Thermographic plugin specifically;
  - a Human losing nothing;
  - Orthoskin 2 on a Troll (Armor −1 +2, trait replaced);
  - Dermal Plating on a Troll;
  - the plan's web acceptance: the strike-through appears, then disappears once the plugin is added.
- `ruff check`, `ruff format --check`, `mypy src`: clean.
